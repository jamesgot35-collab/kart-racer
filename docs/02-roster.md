# Roster: 100 Original Characters

Ten themed sets of ten. Every character has a name, a class (Light / Medium / Heavy), a one-line personality, an idle animation, a victory pose, a select-screen portrait and a **distinct driving silhouette** (a head/body shape hook readable at thumbnail size). All characters are original creations.

## Class split

| Class | Count | Gameplay role |
|---|---|---|
| Light | 33 | Fast acceleration, quick spin-out recovery, weak in bumps |
| Medium | 34 | Balanced |
| Heavy | 33 | Slow acceleration, high top speed, strong bump |

**Total: 100 characters, 100 unique names, 12 free starters.**

## Unlock methods

* **Coins** (about 60 characters): price = 500 + 100 × (set − 1) + 60 × (position in set − 1).
* **Trophies**: position 5 in each set requires a gold trophy in a named cup (cups rotate).
* **Daily challenge streak**: position 8 in each set unlocks after a streak of 3 + set number days.
* **Achievements**: position 10 in each set (the set "capstone") requires a set-specific achievement:

  * Set 1 (Meadow Folk): Win 50 races
  * Set 2 (Neon Harbor): Land 500 drift boosts
  * Set 3 (Frost Peak): Hit 100 rivals with items
  * Set 4 (Dune Runners): Collect 5,000 coins
  * Set 5 (Sky Circus): Use the shortcut on every Seedling and Copper track
  * Set 6 (Deep Reef): Finish a Grand Prix without being hit
  * Set 7 (Clockwork Guild): Win a Versus race with 4 humans
  * Set 8 (Ember Forge): Perform 100 slingshots from a draft
  * Set 9 (Spirit Grove): Land 25 perfect starts
  * Set 10 (Star Cadets): Win a gold Time Trial on 5 different tracks

Voices: each character has 10+ barks in a distinct voice (Light = higher pitch band, Heavy = lower), see the audio section of the GDD.
