## Caveats (honest)
- Never played on a real phone/tablet. All testing is headless Chrome with software GL (5-9 fps), so real frame rate, touch feel and thermals are unmeasured. Audio was verified by capture + measurement, never by ears.
- Browser-to-browser WebRTC is NOT verified: headless Chrome on the build box cannot gather ICE candidates (tests/ice_probe.mjs). The real PeerJS cloud + WebRTC data-channel path is verified Node-to-Node with the actual src/net.js. No TURN server: strict NATs may fail. Host leaving ends the room (no host migration). Remote items replay from events; hit results are authoritative on the victim's client.
- Daily-challenge board is local only. HQ memory: 48 kHz stems decode to ~290 MB per track; High is meant for desktop / recent iPad & iPhone Pro. Standard decodes ~140 MB per track (32 kHz context, mono bass/lead/counter).
- Under software GL a race takes ~50 s wall to reach green (intro runs on game time); real audio prep measured 2.9 s (223 buffers). Title 2.9 s, menu 5.4 s on this box.
- Grand Prix has one cup (4 races) in this slice; other roster/tracks exist as design docs only. Some HQ gfx are applied only to ground/road/sky env (not karts/props).
- Pages repos are ~1 GB each limit-wise fine; HQ pack first download is large (cached afterwards).
